# BAKAR VAI — Arc Reactor & JARVIS Lifestyle Experience

A futuristic, mobile-first portfolio website dedicated to **Bakar Vai**, fully themed in **Iron Man / Arc Reactor & JARVIS** aesthetics.

---

## ⚡ Features

- **Standby Arc Reactor Ignition**: Opens on a dark, dormant standby screen featuring a pulsing Mark-VII Arc Reactor.
- **Synchronized `bakar_06` Detonation**: Tapping **ACTIVATE** triggers an Arc Reactor surge, expands the holographic iris, locks targeting onto Bakar Vai (`bakar_06.png`), detonates the Jericho shockwave blast with camera screen shake, and drops the beat on `06.mp3`!
- **Holographic Animated Visions**: All 6 lifestyle photos of Bakar Vai feature continuous cyan laser scanline sweeps, biometric HUD target brackets, leader lines (`[TARGET: BAKAR VAI]`, `[MATCH: 100%]`), and 3D gyro tilt.
- **Background Soundtrack (No Music Bar)**: Plays seamless soundtracks mapped to each vision (`01.mp3` to `06.mp3`) with an unobtrusive top-right HUD toggle (`[ 🔊 JARVIS AUDIO ]`).
- **Designed for Phone**: 100% optimized for vertical mobile screens with touch-friendly swipe carousel and bottom JARVIS dock.
- **Vercel & GitHub Ready**: Preconfigured with `vercel.json` for zero-config deployment.

---

## 🚀 How to Run Locally

You can run this project locally with Node.js:

```bash
# Start the local server
npm start
```

Or simply double-click `start.bat` on Windows.
Then open: **`http://localhost:3000`**

## 🌐 Deploy to Vercel via GitHub

1. **Initialize Git Repository & Commit**:
   ```bash
   git init
   git add .
   git commit -m "feat: Bakar Vai Iron Man JARVIS experience"
   ```

2. **Push to Your GitHub**:
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/bakar-vai.git
   git push -u origin main
   ```

3. **Deploy on Vercel**:
   - Go to [vercel.com](https://vercel.com) and sign in with GitHub.
   - Click **"Add New Project"** and import your `bakar-vai` repository.
   - Leave Framework Preset as **"Other"** (it is a clean static web app).
   - Click **Deploy**! 🚀
